Dashboard

Typical flow: 1) add students (Roll No, Name, Branch, Batch) or import a PDF/Excel list → 2) add exam rooms → 3) create batches/courses (defaults A–G, plus your own) → 4) upload exam data as PDF/Excel or create exams manually → 5) generate the seating chart and download it as a PDF (with student list). Press Enter in any form to jump to the next field.

Manage Rooms

Type Desks and rows/columns are auto-predicted as a wide, shallow grid —3–4 rows max (12 →3×4,24 →3×8,20 →4×5); or type rows/columns and desks is derived. Capacity = desks × students per desk (auto-filled, still editable).

Required columns: Room Number and Desks. Students per desk defaults to 3; rows, columns and capacity are calculated automatically.
